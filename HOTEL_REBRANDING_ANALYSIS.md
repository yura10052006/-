### 2. Проблеми поточного сайту

#### Технічні (критичні)
- **HTTP 403** для краулерів → Google не індексує сайт → нульовий органічний трафік
- Відсутня `schema.org` розмітка Hotel/LodgingBusiness
- Відсутній Google Business Profile (або не оптимізований)
- Невідомий стан Core Web Vitals (ймовірно незадовільний)

#### Дизайн і UX
- Відсутність єдиної дизайн-системи між сторінками 4 готелів
- Немає емоційного hero-блоку, що захоплює з першої секунди
- Слабка або відсутня мобільна адаптація
- Відсутність мікроанімацій та інтерактивності
- Немає сторітелінгу — сайт схожий на каталог, не на досвід

#### Функціональні
- Незрозуміла система вибору між 4 готелями
- Відсутність або слаба інтеграція системи прямого бронювання
- Немає мультимовності (uk / en / pl)
- Відсутні соціальні докази в реальному часі (відгуки, завантаженість)

### 3. Концепція візуального ребрендингу

**Напрямок:** `Lviv Neo-Heritage` — сучасний clean дизайн із вплетеними архітектурними мотивами Австро-Угорщини. Не ретро, не кіч — а зріла естетика, де деталі будівель стають графічними елементами.

**Три візуальні принципи:**
1. **Архітектурна точність** — геометрія арок, решіток, ліпнини як декоративний код
2. **Теплота матеріалу** — фактури каменю, дерева, металу у кольорах і текстурах
3. **Сучасна читабельність** — мінімалізм у layout, максимум у деталях

## ЧАСТИНА IV. СИСТЕМА АНІМАЦІЙ

### 11. Анімаційна філософія

> **Принцип:** Анімація не для показухи — вона слугує навігації і розповіді. Кожен рух або пояснює ієрархію, або посилює емоцію, або направляє погляд.

**Три рівні анімацій:**
```
L1 — МІКРО (завжди, скрізь)
     Hover стани, focus rings, кнопки, чекбокси
     Тривалість: 150–300ms | Easing: ease-out

L2 — КОМПОНЕНТНІ (при взаємодії)
     Модальні вікна, dropdown, accordion, toast
     Тривалість: 250–400ms | Easing: cubic-bezier(0.16, 1, 0.3, 1)

L3 — СТОРІНКОВІ (scroll-driven, page transitions)
     Hero reveal, section entrances, parallax, page changes
     Тривалість: 600–1200ms | Easing: GSAP CustomEase
```

### 12. Детальна специфікація анімацій

#### 12.1 Page Load / Hero Reveal

```javascript
// GSAP timeline при завантаженні сторінки
const heroTimeline = gsap.timeline({ delay: 0.2 });

heroTimeline
  // Фонове фото: scale from 1.1 → 1.0 (Ken Burns)
  .from(".hero-bg", {
    scale: 1.1,
    duration: 2.0,
    ease: "power2.out"
  })
  // Логотип: fade + slide up
  .from(".hero-logo", {
    opacity: 0,
    y: 30,
    duration: 0.8,
    ease: "power3.out"
  }, "-=1.5")
  // Заголовок: кожне слово окремо
  .from(".hero-title .word", {
    opacity: 0,
    y: 40,
    stagger: 0.08,
    duration: 0.7,
    ease: "power3.out"
  }, "-=0.5")
  // Підзаголовок
  .from(".hero-subtitle", {
    opacity: 0,
    y: 20,
    duration: 0.5
  }, "-=0.2")
  // CTA кнопки
  .from(".hero-cta", {
    opacity: 0,
    y: 15,
    stagger: 0.15,
    duration: 0.4
  }, "-=0.1");
```

#### 12.2 Scroll Animations (ScrollTrigger)

```javascript
// Секційний reveal — стандартний патерн для всіх секцій
gsap.utils.toArray(".section-reveal").forEach(section => {
  gsap.from(section, {
    scrollTrigger: {
      trigger: section,
      start: "top 85%",
      end: "top 50%",
      toggleActions: "play none none reverse"
    },
    opacity: 0,
    y: 50,
    duration: 0.8,
    ease: "power3.out"
  });
});

// Картки готелів — stagger з боків
gsap.from(".hotel-card", {
  scrollTrigger: {
    trigger: ".hotels-grid",
    start: "top 75%"
  },
  opacity: 0,
  y: 60,
  stagger: {
    each: 0.15,
    from: "start"
  },
  duration: 0.7,
  ease: "power2.out"
});

// Brand story — паралакс на фото
gsap.to(".brand-photo", {
  scrollTrigger: {
    trigger: ".brand-section",
    start: "top bottom",
    end: "bottom top",
    scrub: 1.5  // плавно слідує за скролом
  },
  y: -80,  // зміщення за вертикаллю
  ease: "none"
});

// Текст рядок за рядком (split text)
const splitLines = new SplitText(".brand-text", { type: "lines" });
gsap.from(splitLines.lines, {
  scrollTrigger: {
    trigger: ".brand-text",
    start: "top 80%"
```

## ПІДСУМОК

**Три пріоритети ребрендингу (без зміни назви):**

1. **Дизайн** — Lviv Neo-Heritage стиль: чавун + терракота + пергамент, Cormorant Garamond, архітектурні SVG-мотиви. Емоційний, не корпоративний.

3. **Функціонал** — Next.js 14 з SSR, прямий booking engine, мультимовність uk/en/pl, вибір готелю за характером (не за адресою), виправлення SEO-блокування.
